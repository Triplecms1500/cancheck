How this works

The buttons at the top
  • New flavour — tap it whenever a different flavour or product starts on the line. The amber banner “NEW RUN / FLAVOUR” appears and the next can must be checked and PASS before the run carries on. It does not change the customer; use Run setup for that.
  • Run setup — what this tablet is checking right now: the customer (sets the code layout, whether there is an excise line, and the shelf life), the excise code as printed, the canning line (C1 or C2) this tablet sits on, the maximum print age in minutes, and the check timer. Operators tap their name and never type; supervisors add names. Changing the customer, excise code or line starts a new run, so the next can is the first check.
  • Audit log — every scan, newest first, with its result and photo. Tap a row to see the photo and what the reader saw. Records are append-only and chained with SHA-256 hashes, so an edited or deleted row shows up when you tap Verify log integrity. Download CSV or CSV + photos (zip) to keep a copy; this proof of concept stores the log on this tablet only.
  • Tools — supervisor area. See what the reader saw on the last can and teach it the true text; try a photo without logging it; change camera and reader settings (auto-capture, stillness time, resolution, strictness); save or clear the empty-nest picture; download or load the examples the reader has learned; run the rules self-test; and erase the test log.
What happens to each can
  1. Pick the customer. A supervisor chooses whose cans are running. That sets the code layout, whether there is an excise line, and the shelf life.
  2. Set the can down and let go. The camera watches for movement. When the can has been still for 2 seconds it takes the photo itself. Nobody presses a button or types.
  3. Read it twice. The page finds the printed lines, straightens them, and reads each character twice with different image settings. If the two reads differ, or a character is doubtful, the result is RETAKE, never a guess.
  4. Check it against the clock and the run. Printed date and time must be real, not in the future and recent. Expiry equals production date plus shelf life. Excise code, plant code and line must match. The batch is only recorded.
  5. Show PASS, FAIL or RETAKE and log it. A FAIL says STOP THE LINE. Every scan goes into a tamper-evident log with its photo, kept on this tablet.
  6. Check rhythm. A check is due every 30 minutes and before each new flavour.
